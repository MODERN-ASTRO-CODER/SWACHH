SWACHH MODERN WEBSITE PROTOTYPE
Created by Hrishab Shukla, Class IX

START HERE
1. Extract the ZIP file into a folder.
2. Open index.html in Chrome, Edge, or Firefox. The first page introduces SWACHH and explains how to use the shopping, receipt, returns, and rewards flow.
3. Use the Shop link to browse sample products. Complete a demo checkout to save an order and receipt in this browser.
4. Open Orders / Order History to view saved demo orders and receipts. Return & Earn requires a completed SWACHH order receipt and a photo of waste from that purchase.

PAGES
- index.html: Introduction and how-to guide
- marketplace.html: Sample products and basket
- checkout.html: Demo checkout, voucher selection, receipt scanner, and watermarked demo receipt
- orders.html: Order history and saved demo receipts
- pilot.html: Return & Earn demo
- rewards.html: Points balance, voucher redemption, and voucher wallet
- ecoreward.html: Return-and-reward explanation
- account.html / signin.html: Demo account pages
- about.html: Project information
- styles.css / app.js: Shared styling and front-end interactions

DEMO REWARD MODEL
Illustrative rates: ₹2/kg cardboard, ₹3/kg plastic, and ₹4/kg metal. Points convert at 100 points = ₹1. Eligible return rewards are capped at 25% of the linked order total. Voucher behavior and rates are sample values; confirm local scrap prices and funding before any real launch.

DEMO LIMITATIONS
This is a student front-end prototype. Orders and receipts are illustrative browser-local records. No real payment, delivery, account security, waste collection, or recycler integration exists. Use fictional demo credentials only. Receipt OCR loads Tesseract.js from a CDN and requires an internet connection; OCR cannot prove a receipt is genuine.
